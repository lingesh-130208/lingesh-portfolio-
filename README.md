## GitHub deployment
1. Create a new public repository, preferably `lingesh-portfolio`.
2. Extract this ZIP.
3. Upload the contents so `index.html` is in the repository root.
4. Commit to `main`.
5. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
6. Save and open the generated Pages URL.

## Vercel
Import the GitHub repository. No build command is needed.

## Resume
The site expects:
`assets/resume.pdf`

## Certificates
Put public certificate PDFs/images in:
`assets/certificates/`

Then edit the credential section in `app.js` if you want individual View Credential buttons.
